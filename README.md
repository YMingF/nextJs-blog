# Next.js 个人博客系统

这是一个使用现代技术栈构建的个人博客系统，支持文章的发布、编辑和管理。

## 项目特点

- 基于 Next.js 的服务端渲染
- 响应式设计，支持移动端访问
- 文章管理系统
- 用户认证系统

## 技术栈

- **前端框架**: Next.js
- **后端框架**: Express.js
- **数据库**: PostgreSQL
- **ORM**: Prisma
- **容器化**: Docker
- **部署**: 支持自动化部署
